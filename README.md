# Racecar

Transmog your Dom pet to the burrowed form of the Doom of Mokhaiotl. It requires RuneLite's built-in `GPU` plugin and only affects your own pet.

New right click menu options:
- `Metamorphosis`to change between regular Dom and car phase
- `Emote` car phase slam animation (only while burrowed)

## Rendering
The real follower remains in the scene, the plugin only hides its GPU drawing while a replacement model is active.
